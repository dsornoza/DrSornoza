Nota Metodológica

Esta calculadora utiliza la fórmula de Cochran (1977) para muestras probabilísticas. El tamaño calculado es el mínimo estadístico; considera aumentarlo un 10–20% para compensar posibles no-respuestas. Para estudios cualitativos (fenomenológicos, etnográficos), el tamaño se determina por saturación teórica, no por fórmulas.
